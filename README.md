# Compile
Để có thể build Thesieutoc theo phiên bản của server bạn, xem repo của khứa [AnvilGUI](https://github.com/WesJD/AnvilGUI) và chỉnh version trong file pom.xml. VD: 1.21.4 thì dùng 1.10.4-SNAPSHOT. Dùng `mvn clean package` để build.
